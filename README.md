Random Password Generator 
Welcome! This is my very first web project. It is a simple tool to generate strong, random passwords and copy them quickly.

1. Features
   Generate Passwords: Create strong and random passwords with one click.
   Easy Copy: Copy the generated password to your clipboard easily.
   Simple UI: Clean and easy-to-use interface.
   
2. Tech Stack
   HTML - Page structure
   CSS - Styling and design
   JavaScript - Logic for password generation and copying
